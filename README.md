# Bot Apartamentos Ricaurte - Arte Diverso

Bot de Telegram para arriendo de apartamentos vacacionales en Ricaurte, Cundinamarca.

## Características
- Respuestas automáticas 24/7
- Base de datos de clientes
- Información completa del apartamento
- Consultas de disponibilidad

## Comandos
- `/start` - Mensaje de bienvenida
- `/info` - Detalles del apartamento
- `/fotos` - Galería de imágenes
- `/tarifas` - Precios y tarifas
- `/disponibilidad` - Consultar fechas
- `/ubicacion` - Ubicación y turismo
- `/contacto` - Datos de contacto

## Deploy en Northflank

1. Crear cuenta en https://app.northflank.com
2. Crear nuevo proyecto desde GitHub
3. Configurar variables de entorno (.env)
4. Deploy automático
